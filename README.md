# منشئ فواتير مؤسسة يوسف عيد المطيري لقطع غيار السيارات

موقع ثابت يعمل على GitHub Pages بدون خادم خلفي وبدون قواعد بيانات أو اشتراكات.

## النشر على GitHub Pages

1. أنشئ مستودعًا جديدًا في GitHub.
2. ارفع جميع الملفات الموجودة في هذا المجلد إلى جذر المستودع.
3. افتح **Settings** ثم **Pages**.
4. من **Build and deployment** اختر **Deploy from a branch**.
5. اختر الفرع `main` والمجلد `/ (root)` ثم اضغط **Save**.

## التخزين

- بيانات الرقم الضريبي والشعار والإعدادات تُحفظ في `localStorage` داخل المتصفح.
- الفواتير المحفوظة تظهر في قسم **المحفوظات** على نفس الجهاز والمتصفح فقط.
- حذف بيانات المتصفح يؤدي إلى حذف المحفوظات المحلية.

## الملفات الرئيسية

- `index.html` واجهة الموقع.
- `assets/css/style.css` التنسيق والطباعة.
- `assets/js/app.js` الحسابات، PDF، المشاركة، QR، والمحفوظات.
- `.nojekyll` لضمان عمل المسارات الثابتة على GitHub Pages.
